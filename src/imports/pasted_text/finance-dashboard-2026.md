# Prompt para gerar o novo Dashboard Financeiro 2026 no Zip (baseado no Figma aprovado)

## Contexto do Projeto

Criar uma nova versão do dashboard financeiro institucional com base no modelo já aprovado no Figma anterior. O novo projeto será construído a partir da planilha financeira “PC Financeira 2026”, mantendo a mesma linha visual, identidade institucional e padrão de navegação do dashboard original.

O sistema já possui um modelo funcional e aprovado. Portanto, este novo dashboard deve seguir a mesma lógica estrutural, UX e UI, porém adaptado para a nova planilha, novas abas e novas necessidades analíticas.

## Objetivo

Transformar a planilha financeira “PC Financeira 2026” em um dashboard moderno, institucional, responsivo e visualmente organizado.

O dashboard deve:

* Facilitar leitura financeira;
* Organizar dados por categorias e períodos;
* Possuir navegação intuitiva;
* Ser modular;
* Seguir o padrão visual já existente no projeto anterior;
* Expandir a estrutura atual para suportar mais páginas e sub-abas.

# Estrutura Geral do Dashboard

O novo dashboard terá mais páginas e sub-abas do que o modelo anterior.

Criar arquitetura escalável e organizada.

## Estrutura sugerida

### 1. Dashboard Geral

Visão macro do projeto.

Componentes:

* Valor total solicitado;
* Valor total executado;
* Diferença financeira;
* Percentual executado;
* Cards financeiros principais;
* Gráfico comparativo entre solicitado e executado;
* Linha temporal mensal;
* Evolução dos gastos;
* Distribuição por rubricas.

---

### 2. Financeiro

Subdividir em sub-abas:

#### 2.1 Resumo Financeiro

* KPIs gerais;
* Totais por mês;
* Totais acumulados;
* Indicadores de saldo.

#### 2.2 Rubricas

Baseado nas categorias financeiras da planilha:

* Equipe;
* Reportagens;
* Comunicação;
* Equipamentos;
* Formação;
* Site;
* Consultorias;
* Outras rubricas.

Cada rubrica deve possuir:

* Total solicitado;
* Total executado;
* Diferença;
* Evolução mensal;
* Indicadores visuais.

#### 2.3 Comparativo Mensal

Criar visualizações:

* Solicitado x Executado;
* Comparativo mês a mês;
* Gráficos de barras;
* Gráficos de linha;
* Tendências.

---

### 3. Plano de Trabalho

Criar uma seção específica para o plano de trabalho.

Sub-abas:

#### 3.1 Atividades

* Lista de atividades;
* Entregas realizadas;
* Status;
* Organização por eixo;
* Timeline.

#### 3.2 Execução

Relacionar:

* Atividade;
* Rubrica vinculada;
* Justificativas;
* Progresso.

#### 3.3 Relatórios

Visual institucional para:

* Resumos;
* Observações;
* Justificativas;
* Insights operacionais.
