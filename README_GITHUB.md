# Dashboard Financeiro FAJ 2026

Dashboard institucional de prestação de contas e monitoramento financeiro desenvolvido para a FAJ e Caluna Comunicações.

## Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Funcionalidades
- Dashboard financeiro institucional
- Comparativo Solicitado vs Executado
- Timeline Dez/2025 → Maio/2026
- Prestação de contas
- Visualização de comprovantes
- KPIs financeiros
- Relatórios e rubricas

## Estrutura recomendada
```
src/
components/
data/
assets/
public/
```

## Instalação local

```bash
npm install
npm run dev
```

## Build produção

```bash
npm run build
```

## Deploy recomendado
- Vercel
- Netlify
- Cloudflare Pages

## Observações
- Não subir PDFs de comprovantes diretamente no GitHub.
- Utilizar links do Google Drive ou storage externo.
- Os comprovantes devem ser vinculados por URL.
